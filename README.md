# Mental-Health-Wellness-Web-Application

HappyBird 🕊️ <br>
HappyBird is a mental health and wellness web application developed using Python, Django, and SQLite3. It offers a supportive digital environment where users can engage in mindfulness practices, track emotions, and boost mental well-being. 

🌟 Features

😊 Mood and emotion tracking for daily reflections

🧘‍♀️ Meditation and relaxation content with embedded video sessions

📓 Personalized journaling feature for self-expression

📈 Monthly charts to visualize mental health trends

🤖 AI-powered chatbot for mental health conversations

🔔 Motivational quotes that change periodically

👤 User authentication and profile management

📁 Clean and organized project structure with modular Django apps

Frontend: HTML, CSS, Bootstrap

Backend: Python, Django

Database: SQLite3

Media: YouTube embedding for guided sessions

AI Features: Integrated chatbot (placeholder or simple NLP)

🚀 How to Run the Project

Clone the repository <br>
git clone https://github.com/yourusername/happybird.git <br>
cd happybird <br>

Create a virtual environment <br>
python -m venv venv <br>
source venv/bin/activate  # On Windows: venv\Scripts\activate <br>

Install dependencies <br>
pip install -r requirements.txt <br>

Apply migrations <br>
python manage.py makemigrations <br>
python manage.py migrate <br>

Run the development server <br>
python manage.py runserver <br>
Access the application Open http://127.0.0.1:8000/ in your browser.
